Kebijakan Privasi

Lei Stuff · berlaku sejak 15 November 2026

Lei Stuff adalah aplikasi menulis yang berjalan sepenuhnya di browsermu. Tidak ada server milik Lei Stuff yang menyimpan atau membaca tulisanmu.

Data yang disimpan

  • Di perangkatmu: tulisan, catatan, to-do, dan pengaturan disimpan di penyimpanan browser (IndexedDB) agar bisa dipakai tanpa internet.
  • Di Google Drive-mu: bila kamu menyambungkan Google Drive, salinan data disimpan sebagai file lei-stuff-data-*.json di folder Drive yang kamu pilih sendiri.

Izin Google yang diminta

  • Google Drive (drive.file): hanya untuk membuat, membaca, dan memperbarui file yang dibuat Lei Stuff atau yang kamu pilih lewat jendela pemilih file. Lei Stuff tidak bisa melihat file Drive lainnya.
  • Google Calendar (calendar.events): hanya untuk membuat, mengubah, dan menghapus acara tenggat lomba yang kamu tautkan dari Lei Stuff.

Token akses Google hanya disimpan sementara di memori browser dan tidak dikirim ke pihak lain.

Berbagi data

Lei Stuff tidak menjual, membagikan, atau mengirim datamu ke pihak ketiga, dan tidak memakai iklan maupun pelacak. Penggunaan data yang diterima dari Google API mengikuti Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data

Hapus data situs di pengaturan browser untuk menghapus salinan di perangkat. Hapus file lei-stuff-data-*.json di Drive untuk menghapus salinan di Drive. Cabut akses Lei Stuff kapan saja di myaccount.google.com/permissions.

Kontak

Pertanyaan tentang privasi bisa diajukan lewat halaman Issues repositori Lei Stuff.
